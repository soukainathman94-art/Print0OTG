# Print OTG — مشروع Android (الإصدار 1.2)

تطبيق تجريبي للطباعة المباشرة عبر USB OTG، يستهدف طابعة HP LaserJet P2055d.

## ما الذي يتضمنه؟
- اختيار PDF أو صورة من الهاتف.
- طلب إذن USB من Android.
- إرسال صفحات PDF والصور كرسوم نقطية PCL raster.
- عدد النسخ وخيار 300/600 DPI.
- واجهة عربية.

## ما الذي لا يتضمنه بعد؟
- ملفات Word لا تُحوّل داخل التطبيق في هذه النسخة؛ افتح DOC/DOCX في Microsoft Word أو WPS Office وصدّره إلى PDF أولاً.
- لا توجد معاينة مرئية للصفحة داخل التطبيق في هذه النسخة.
- لم يتم اختبار المشروع فعلياً على طابعة المستخدم؛ نجاح الطباعة المباشرة يعتمد على واجهة USB ونسخة لغة PCL التي تقبلها الطابعة والـ firmware.
- هذه نسخة مصدر أولية وليست APK جاهزاً.

## البناء
1. افتح المشروع في Android Studio حديث.
2. انتظر مزامنة Gradle.
3. اختر Build > Build APK(s).
4. ثبّت APK على هاتف Android.
5. صِل الطابعة عبر OTG، وافق على إذن USB، ثم جرّب صفحة PDF بسيطة.

## تنبيه تقني
إرسال PCL raster الخام ليس بروتوكولاً عاماً مضموناً لكل طابعة USB. إذا لم تطبع الطابعة، استخدم HP Print Service Plugin أو تعريف طباعة Android المتوافق مع الطابعة، ثم عدّل طبقة الإرسال بعد معرفة USB interface/protocol الفعلي.

## تغييرات الإصدار 1.1
- إصلاح انهيار التطبيق عند اختيار ملف (إذن URI الدائم).
- اختيار الجهاز والواجهة الصحيحين (USB class 7) وحجز واجهة واحدة وتحريرها بعد الطباعة.
- الرسم والإرسال على شرائح من 128 صفاً: لا نفاد ذاكرة عند 600 نقطة/بوصة.
- إرسال صفوف كثيرة في عملية نقل واحدة (أسرع بكثير).
- تظليل (dithering) للصور بدل عتبة سوداء/بيضاء، ومراعاة اتجاه الصورة EXIF.
- أوامر PCL كاملة: حجم A4، الاتجاه (أفقي تلقائياً)، النسخ، الهوامش، إنهاء الوظيفة.
- لم يُجرَّب على طابعة حقيقية ولم يُترجَم في بيئة التطوير؛ قد تحتاج تعديلاً بسيطاً.

## تغييرات الإصدار 1.2
- **ميزة جديدة:** تصغير/تكبير المحتوى قبل الطباعة من 25% إلى 200% (شريط تمرير + أزرار ±5% + زر 100%). 100% = ملاءمة الصفحة. ما يتجاوز حدود الصفحة عند التكبير يُقصّ.
- خيار محاذاة للأعلى بدل التوسيط عند التصغير.
- حفظ آخر إعدادات (الدقة والحجم والمحاذاة) بين مرات التشغيل.
- إصلاح ترتيب النسخ: ملف PDF متعدد الصفحات يُطبع الآن مجمّعاً (1،2،3،1،2،3) بدل (1،1،2،2،3،3).
- إصلاح: تدوير الشاشة كان يعيد إنشاء النشاط ويضيّع الملف المختار؛ أصبح يُحتفظ بالحالة.
- إصلاح: قراءة الإعدادات (الدقة/النسخ) داخل خيط الطباعة قد تتغير أثناء الطباعة؛ تُلتقط الآن مرة واحدة عند الضغط.
- إبقاء الشاشة مضاءة أثناء الطباعة كي لا ينقطع الإرسال.
- رسالة واضحة عند PDF فارغ.
